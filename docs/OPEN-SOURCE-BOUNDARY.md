# 開源邊界

## 目前公開範圍

本 Repository 目前公開 NetOptimizer 的核心功能：

- 網路介面偵測與健康探測。
- A/B 備援切換、復原與回滾。
- 慢速 EWMA 智慧選路。
- Windows InterfaceMetric、route、ARP 與 MTU 的管理員權限邊界。
- UI、診斷輸出、建置腳本與自動化測試。

這些內容依根目錄 `LICENSE` 的 MIT License 提供。程式不應包含 API 金鑰、密碼、個人診斷記錄或其他服務端密鑰。

## 未來商業模組

若未來加入付費功能，會與公開核心分離，例如：

- 付費授權與訂閱驗證服務。
- 僅對付費使用者提供的雲端整合或管理後台。
- 商業專用整合、客製部署與支援工具。

商業模組不得要求公開核心內嵌私密金鑰，也不應把私有服務端原始碼放入本 Repository。公開核心應能在沒有商業服務憑證時正常建置與執行。

## 發布原則

- 公開 Repository：核心原始碼、可重現建置腳本、測試與必要文件。
- GitHub Release：一般使用者需要的已建置 EXE、可攜版與校驗檔。
- 私有發布：商業模組、服務端程式、部署憑證與客戶專用內容。

未來若真的出現商業模組，會在新增模組前先明確標示其授權與發布範圍，不以「閉源 EXE」假設達到秘密保護效果。
